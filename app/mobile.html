Music

Sonos speakers on this network

Found automatically over Wi-Fi — no pairing, no account. This controls the speaker directly: play, pause, skip, volume, and what it's playing right now.

Spotify Connect

Create a free app at developer.spotify.com, add http://127.0.0.1:8787/api/spotify/callback as a Redirect URI, and paste the Client ID here. There's no client secret — this uses PKCE, so nothing secret is stored.

The Connect button has to be pressed on the Mac mini itself, in a browser there. Spotify only accepts 127.0.0.1 redirects, and on your phone that address means your phone. Once it's connected, controlling it from here works fine.

Handing playback to a Sonos needs Spotify Premium — that's Spotify's rule for controlling playback through their API, not this app's.

Play on this screen

This player makes sound on the Mac mini's own audio output. Pair a Bluetooth speaker to the Mac in macOS System Settings and this comes out of it. Free Spotify accounts get 30-second previews here; Premium plays in full.

About Bluetooth and Sonos

No app — this one or any other — can push audio to a speaker over Bluetooth from a web page. Bluetooth audio (A2DP) lives in the operating system; the only Bluetooth a browser can speak is for small data, not sound. And most Sonos speakers have no Bluetooth audio input at all — they're Wi-Fi devices.

So there are two real routes, and both are better than Bluetooth would have been:
  • Sonos: use Spotify Connect above. Audio goes Spotify → speaker over Wi-Fi, never through this Mac. No pairing, no range limit, no quality loss.
  • Any Bluetooth speaker: pair it to the Mac mini once in macOS System Settings → Bluetooth, then set it as the output device. Everything the Mac plays, including the player above, goes there.

Baja

Anthropic API key (paid, best quality)
Stored only on this local server, never sent anywhere except directly to Anthropic when Baja needs to answer a question. Usage-based — roughly a fraction of a cent per question.
Or: Groq API key (free)
Free, no card: sign up at console.groq.com, create a key and paste it here. Used when there's no Anthropic key.
Or: free local model name (via Ollama)
If neither key is set above, Baja automatically tries this model through Ollama running locally on this Mac mini — completely free, no internet needed for the answer itself, nothing sent anywhere. Install Ollama, then run ollama pull llama3.2 once in Terminal. Small models (1B–3B) run fine on any Mac mini from the last few years.
Baja is not Apple's Siri — there's no public API that lets a third-party app plug into Siri's brain. Baja is a real, working alternative built on your browser/Electron's own continuous speech recognition, which typically runs through the OS/browser's speech service rather than fully on-device, so listening itself still needs an internet connection even when the answering part is free and local.

Say "Baja" anywhere near the kiosk, either with your question in the same breath ("Baja, what's next?") or just the name — it'll say "Yes?" and listen for a moment. A few things it always handles instantly, no model needed:
  • "Add [item] to the grocery list"
  • "What's next?"
  • "What's the weather?"
Anything else is answered by whichever of the two options above is configured, with today's schedule and grocery list included as context. Neither configured → Baja says so out loud instead of failing silently.

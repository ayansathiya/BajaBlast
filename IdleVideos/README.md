# Idle Videos

Drop .mp4 files here to use them as idle/ambient screensaver backgrounds
instead of the generated gradients. See the README's "Adding idle videos"
section for how to wire a scene to a specific video (e.g. a beach clip for
vacation events, snowy footage for winter events).

This folder ships empty — no videos are bundled — so the demo works fully
offline with the generated-gradient background mode (the default).
